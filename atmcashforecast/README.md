# Cash Forecasting

This project is a machine learning-based cash forecasting system that predicts future cash withdrawals for ATMs. It uses synthetic data generation, preprocessing, and a Random Forest model to make predictions.

## Features and enhancements  
- **Synthetic Data Generation**: Generates realistic ATM cash withdrawal data for training and testing.
- **Dynamic Holiday Calculation**: Calculates the number of days until the next holiday (e.g., Christmas).
- **Machine Learning Model**: Uses a Random Forest Regressor for cash withdrawal predictions.
- **Future Predictions**: Predicts cash withdrawals for the next 14 days.

Usage
1. Generate Synthetic Data
Run the script to generate synthetic ATM data:

python [cash_forecasting.py](http://_vscodecontentref_/1)

This will create a file named atm_data.csv containing the generated data.

2. Train the Model
The script automatically trains a Random Forest model using the synthetic data. The trained model is saved as cash_forecasting_model.pkl.

3. Predict Future Withdrawals
The script predicts cash withdrawals for the next 14 days and saves the results in future_predictions.csv.

File Structure
cash_forecasting.py: Main script containing data generation, preprocessing, model training, and prediction logic.
requirements.txt: List of required Python libraries.
atm_data.csv: Synthetic ATM data generated by the script.
future_predictions.csv: File containing the predicted cash withdrawals for the next 14 days.

Key Functions
generate_synthetic_data()
Generates synthetic ATM data with features like:

date: Date of the transaction.
atm_id: Unique identifier for each ATM.
location_type: Type of ATM location (Urban, Suburban, Rural).
foot_traffic: Randomly generated foot traffic data.
cash_withdrawn: Simulated cash withdrawal amounts.
preprocess_data(df)
Prepares the data for training by:

Converting dates to datetime format.
Calculating days_until_holiday dynamically.
Adding features like is_weekend and is_month_end.
train_model(X_train, y_train)
Trains a Random Forest Regressor using the preprocessed data.

Customization
Change the Current Date
To change the current date used for synthetic data generation and predictions, modify the following line in cash_forecasting.py:

current_date = pd.Timestamp("2025-05-11")

Adjust Prediction Period
To change the number of days for future predictions, update the periods parameter in the predict_future function:

future_dates = pd.date_range(start=last_date + pd.Timedelta(days=1), periods=14, freq='D')
